## Description

This repository contains the code developed for a Master’s Thesis focused on the application of deep learning techniques to the reconstruction of gamma-ray extensive air showers (*Extensive Air Showers*, EAS) in the context of the future **Southern Wide-field Gamma-ray Observatory (SWGO)**.

The main methodology combines:

- **DeepSets**, used to process events containing a variable number of activated detector units.
- **Conditional Normalizing Flows (CNF)**, used to model the joint probabilistic distribution of the reconstructed physical parameters.

The main objective is to reconstruct:

- The shower core position.
- The arrival direction.
- The primary energy.

In addition to point estimates, the model provides posterior distributions for each event, allowing the reconstruction uncertainties to be studied.

## Final Architecture

The final architecture consists of two main components.

### DeepSets

Each event is represented as an unordered set of activated detector units.

Each detector is processed independently by a shared neural network. The resulting detector-level representations are then combined using a **masked mean aggregation**, producing a fixed-dimensional vector that summarizes the global information of the air shower.

This representation is used as the conditioning vector for the normalizing flow.

### Conditional Normalizing Flow

The normalizing flow models the joint posterior distribution of the target variables conditioned on the representation generated by DeepSets.

The six internal target variables are:

- `coreX`
- `coreY`
- `sinZenith`
- `sinAzimuth`
- `cosAzimuth`
- `logEnergy`

These six variables are subsequently converted into five physical quantities:

- Shower core X coordinate.
- Shower core Y coordinate.
- Zenith angle.
- Azimuth angle.
- Primary energy.

The zenith angle is reconstructed as:

\[
\theta = \arcsin(\sin\theta)
\]

while the azimuth angle is reconstructed as:

\[
\phi = \operatorname{atan2}(\sin\phi,\cos\phi)
\]

## Data

The data used in this project were obtained from Monte Carlo simulations of gamma-ray events developed within the framework of the SWGO collaboration.

The original dataset contains several million simulated events. Due to computational constraints and the iterative nature of model development, a subset of **50,000 events** was used for the development and evaluation of the final architecture.

The dataset was divided as follows:

- 80% training.
- 10% validation.
- 10% test.

The test set was kept separate from the training process and was used only for the final performance evaluation.

The comparison with conventional reconstruction methods was carried out using the same test events.

The original SWGO simulation data are not distributed in this repository.

---

## Input Variables

Each activated detector unit is represented using spatial, temporal, charge-related, and geometrical information.

The input information includes:

- Detector position.
- Time relative to the first hit.
- Time difference between consecutive hits.
- Recorded charge.
- Charge fraction relative to the total event charge.
- Position relative to the charge-weighted center of mass.
- Information related to the local detector density or effective detector area.

When an event contains more than 1024 hits, only the 1024 hits with the highest recorded charge are retained.

## Uncertainty and Calibration

One of the main features of the proposed model is its ability to produce complete posterior distributions instead of a single deterministic prediction.

From these posterior distributions, the following quantities are obtained:

- Median.
- Percentiles.
- Credible intervals.
- Empirical coverage.
- Calibration factors.

Calibration factors are estimated using the validation set and subsequently applied without further adjustment to the test set.

---

## Comparison with Conventional Reconstruction Methods

The neural network results are compared with conventional reconstruction methods available for the same simulated events.

The comparison includes:

- Shower-core reconstruction error.
- Energy reconstruction error.
- Angular resolution.
- Performance for peripheral events.
- Prediction uncertainties.

Using the same test events for both approaches ensures a direct and homogeneous comparison.
